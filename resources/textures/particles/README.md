# Particle Textures

Phase 26-B renders particles using `finevox::render::ParticleAtlas`, which
packs every PNG here into a single atlas texture at startup. The
`atlas_region` field in each `.particle` file references a tile by its
filename stem.

## Expected regions

| Region name     | Used by                          |
|-----------------|----------------------------------|
| block_fragment  | finevox:block_fragment           |
| splash_drop     | finevox:splash_drop              |
| flame           | finevox:torch_flame              |
| dust_puff       | finevox:footstep_dust            |
| spark           | finevox:spark                    |
| smoke_puff      | finevox:smoke_puff               |

## Authoring notes

- Recommended tile size: **28×28 RGBA**. The atlas cell is 32×32 with a
  2-pixel replicated border for bilinear-filtering safety (same convention
  as BlockAtlas). Other sizes are scaled nearest-neighbor at load.
- Per-particle `start_tint` / `end_tint` multiply the sampled texel, so
  most tiles can stay near-white; colourize in the `.particle` data when
  convenient.
- If this directory is empty the atlas falls back to a 1×1 white texture
  — particles still render as tinted quads.

The placeholder PNGs currently in this directory are obvious temp art
(soft circles, a streak, a speckled square) generated by a small Pillow
script. Replace with real textures once Shattered Lands art is ready;
keep the filename stems identical so no `.particle` files need changes.
